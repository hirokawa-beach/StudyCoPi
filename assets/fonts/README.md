# 日本語フォント

Noto Sans JPの可変フォント（100〜900）を同梱しています。
Web版のWOFF2とAndroid版のTTFは同じ公式フォントを使用します。
日本語の字形を端末の言語設定に依存させず、オフラインでも表示します。

取得元: https://github.com/google/fonts/tree/main/ofl/notosansjp

ライセンスは同じディレクトリの `OFL.txt`（SIL Open Font License 1.1）です。
Android版にも `app/src/main/assets/NotoSansJP-OFL.txt` を同梱しています。

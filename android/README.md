# StudyCoPi Android

Kotlin + Jetpack Composeで作ったAndroid版です。WebView・Capacitorは使いません。
Android 8.0（API 26）以降に対応します。Web版はリポジトリ直下に残しています。

## v1.4.1

- Androidウィジェットを6種類に追加：今日の学習、今日の予定、今日の勉強時間、累積予定時間と勉強時間、次の目覚まし、次の学習予定。長押しでサイズを変更すると表示も切り替わります。
- Web・Androidの「その他 → StudyCoPiについて」に、バージョン、開発者、ライセンス、更新・報告ページを追加しました。
- 起床問題は数学・英語・世界史・おまかせから選択できます。英語・世界史を各20問収録し、各ステップ1〜10問。英語・世界史は4択で、2段階を通じて同じ問題を繰り返しません。NFC解除も使えます。
- 「その他 → 通知設定」で予定時刻の集中モードをオンにできます。タイマーを開始せずに集中画面を開き、「勉強を始める」で計測を開始します。完了済み、開始から5分以上経過した予定、計測中の別タイマーは対象外です。
- Androidは前面で画面固定のOS確認を求め、バックグラウンドでは通常の通知から開きます。通常アプリは無断で他アプリを閉じたり、解除不可能な固定をしたりできません。Webは開いているページ内の集中画面で、端末全体は固定できません。
- アカウント連携・自動同期は今回の対象外です。既存のJSONバックアップで端末間のデータを移行できます。

## 機能

- 今日の予定、完了チェック、取り消し、実績時間とメモ
- 学習予定の追加・編集・削除、試験・教科・状況による絞り込み、週間の日別表示
- 年に複数回ある考査・模試の登録、過去の試験の年別表示、教科ごとの日程と試験範囲
- 試験別・教科別・期間別の予定時間と勉強時間
- 集中タイマー、一時停止、通知欄からの操作、画面を閉じた後の復元
- 集中モードのAndroid標準の画面固定、終了時の固定解除・勉強時間の記録
- 曜日を指定できる目覚まし、計算問題 → NFCタグまたは追加の計算問題による2段階解除
- 教科の追加・編集・色・並び替え
- 学習予定の開始前・試験前日・タイマー終了のAndroid通知
- JSONバックアップの保存・復元（Web版のv3と旧形式を読み込み可能）

## 音源・時間割・ウィジェット（1.4）

- WebとAndroidでベル・電子音・チャイムの3種類を選択・試聴できます。同じオリジナルWAV音源を共有します。
- Androidの目覚ましでは端末の標準音と音声ファイルも選択できます。別の端末へ復元すると端末固有の音源は標準音に戻ります。
- Webの音源設定は「その他 → 通知設定 → アラーム音」にあります。画面を開いている間のタイマー終了音に適用します。
- Webのホーム画面・ブラウザ・通知アイコンをAndroid版と統一しました。
- Webは最後のバックアップから3日以上経ち、変更がある場合だけ、次に開いた際にバックアップを案内します。「あとで」は24時間の延期です。初回は利用開始から3日を基準にします。
- 両方の「予定 → 時間割」で縦軸が時間の週間表を開けます。短い予定の枠は教科名に合わせて伸び、表示が重なる予定は横に並びます。枠の先頭は実際の開始時刻です。
- Androidの「その他 → ウィジェット」で、今日の予定3件と記録済みの勉強時間をホーム画面に追加できます。保存時に更新され、↻でも更新できます。

音源の原本は `shared/sounds/`、生成コードは `scripts/generate-sounds.py` にあります。WebはService Worker、AndroidはAPK assetsに保存するため、オフラインでも利用できます。

## チュートリアルと共通UI（1.3）

Web・Androidともに、初回に5ステップの使い方を表示します。
試験の登録 → 予定の追加 → タイマー → 実績の記録 → 統計の順で、実際の画面を確認します。
対象のボタンやカードをハイライトし、その近くに短い案内を重ねて表示します。
記録の操作例は表示だけで、保存データに追加されません。
「あとで」で閉じられ、初回終了後は「その他 → 使い方 → チュートリアルを見る」から再表示できます。
使い方には操作別の説明と該当画面へのボタンもあります。チュートリアルは学習データを変更しません。

スマホ版WebはAndroidに合わせた5つのタブ（今日・予定・試験・統計・その他）、
予定カード、配色、日本語フォント、週間の日付選択、円形タイマーを使用します。
画面固定とNFC目覚ましはAndroid版で利用できます。学習データの端末間移行にはバックアップを使います。

共通の説明文はリポジトリ直下の `shared/study-guide.json` が原本です。
WebはService Workerでオフライン用に保存し、Androidは同じファイルをAPKのassetsに組み込みます。
説明の更新時はこのファイルを編集し、初回ガイドを再表示する場合は `version` を増やします。

## UI（1.1）

アイコン付き下部ナビ、固定ヘッダーの追加ボタン、予定カード、試験カード、円形タイマーに更新しました。
淡い背景と白いカード、控えめな青緑の操作色を使用し、端末のダークモードにも対応します。
追加ボタンが予定の開始・記録を覆わないよう、ヘッダーに配置しています。

週間表示は日付を選んで予定カードを表示します。カードの高さは本文に合わせて伸びるため、
1分・5分の予定でも長い教科名が隠れません。週の集計は表示中の週だけを対象にします。
日本語版Noto Sans JPの可変フォントを同梱し、端末が英語設定でも日本語の字形を使用します。
日付選択などのAndroid標準ダイアログも日本語で表示します。フォントはオフラインで利用可能です。
フォントのSIL Open Font LicenseはAPK内の`assets/NotoSansJP-OFL.txt`に含めています。

データはアプリ専用の端末内ファイルに保存します。クラウド同期はありません。
バックアップをWeb版から出力し、Android版の「その他 → バックアップ → ファイルから復元」で引き継げます。
アプリ版のバックアップもWeb版に読み込めます。復元前に現在の記録を保存してください。

## ビルド

Android Studioでこの`android`フォルダを開いてください。
Gradle 9.4.1、Android Gradle Plugin 9.2.1、組み込みKotlin 2.2.10、Compose BOM 2026.02.01を使用します。
SDK Platform 36.1とJava 17以上が必要です。Android Studio付属JDKでもビルドできます。

PowerShellから実行する例：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
```

開発用APKは`app/build/outputs/apk/debug/app-debug.apk`です。
軽量化したローカル配布用APKは`.\gradlew.bat :app:assembleLocal`で作成します。
出力先は`app/build/outputs/apk/local/app-local.apk`です。
USBデバッグを有効にした端末に、Android StudioのRunまたは`adb install -r`で入れられます。
どちらも開発用の署名です。local版はR8とリソース削減を有効にし、UIデバッグ用ライブラリを含めません。
ストア配布用の署名・掲載はまだ行っていません。

## タイマーと通知

経過時間は単調増加クロックで計算し、一時停止時間を除外します。
開始時刻・累積時間・停止状態を永続化し、端末の再起動後には保存した時刻から復元します。
終了予定はAlarmManagerに予約します。常駐サービスや画面のWakeLockは使いません。
アラーム受信と画面側の終了処理は同じリポジトリで直列化し、二重に記録しない設計です。

Android 13以降では通知許可が必要です。Android 12以降では「正確なアラーム」の許可がない場合、
画面を閉じている間の通知が遅れる可能性があります。タイマー画面と通知設定から許可できます。
通知が遅れても実績時間は設定した時間で上限を設けます。
Androidの強制停止中はアラームが実行されません。再度アプリを開くと時間を復元します。
端末メーカー独自の省電力設定での通知挙動は実機で確認してください。

## テスト

JUnitで試験別の分離、実績0分、部分記録、タイマーの累積・一時停止・時計変更・二重終了、
バックアップ互換性と不正データの拒否を確認します。
RobolectricでAndroid 8/15の永続化・破損ファイルの保持を確認し、Composeの操作テストで
試験作成 → 学習予定 → 完了 → 取り消しと、タイマー・統計・バックアップへの移動を確認します。
テストの画面画像はリポジトリ直下の`.artifacts/android`に出力します。

Android版のソースとGradle Wrapperはこのリポジトリに含めています。
ビルド生成物、ローカルSDKの設定、署名キーは含めません。

## 画面固定・目覚まし（1.2）

タイマー実行中に「画面を固定して集中」を選び、集中モードで「画面固定を開始」を押します。
Androidの確認画面で許可するとホーム・他アプリへの移動を抑えられます。
タイマー終了時や「終了して記録」で勉強を終えると固定を解除します。
一般のアプリで使える画面固定のため、Android所定の操作による解除は可能です。
確認画面が出ない場合は、端末設定の「アプリの固定」を有効にしてください。

「その他 → 目覚まし → 追加」で時刻、繰り返す曜日、計算問題の数（1〜5問）、ステップ2を設定します。
最初に足し算を解き、続いて登録したNFCタグを読むか、追加の掛け算を解くと停止します。
NFCを選ぶ場合は実機で「NFCタグを読み取って登録」を使い、タグを1階など移動する場所へ置いてください。
固定UIDのNFCタグを使用します。タグへの書き込みは行いません。NFCは通常ロック解除後に読めます。
NFC非対応の端末・エミュレーターでも計算問題の解除は使えます。
タグを紛失した場合などは「緊急停止」を10秒長押しできます。アクセシビリティ操作では確認画面を表示します。

通知・正確なアラームの許可が必要です。未許可の間はオフで保存できます。
Android 14以降でロック中に解除画面を開くには全画面通知の許可も必要です。
未許可なら通知をタップして解除画面を開きます。目覚まし一覧から各設定へ進めます。
「今すぐテスト」で解除操作と音を試せます。音量は端末のアラーム音量に従い、消音や「おやすみモード」の制限を無視しません。
画面を閉じても、鳴っている間だけフォアグラウンドサービスで音と振動を継続します。
解除の進捗を保存し、画面回転・再作成でも維持します。複数の目覚ましは順番に解除します。
再起動時は予約を再設定し、鳴っていた目覚ましは正確なアラーム経由で再開します。
15分以上過ぎた未実行の目覚ましは、1回だけなら無効化し、繰り返しなら次回へ進めます。
強制停止中は鳴りません。Galaxyの省電力設定や実際のNFCタグ読み取りは実機で確認が必要です。

目覚まし設定はJSONのAndroid専用領域にも保存します。バックアップからの復元時はオフになり、解除中の状態は移しません。
Web版のバックアップ（Android専用領域なし）を取り込む場合、端末の目覚まし設定は維持します。
RobolectricでAndroid 8/15の予約・権限拒否・再起動用予約・鳴動サービス停止を、Composeで2段階解除・画面再作成・緊急停止確認・集中モードの操作を検証します。
